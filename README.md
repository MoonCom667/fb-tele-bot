# متجر مكتب القمر للحاسبات | Al-Qamar Computers 🖥️🚀

منصة تجارة إلكترونية متكاملة وتفاعلية لمكتب القمر لتكنولوجيا الحاسوب في شارع الصناعة - بغداد.
المشروع مبني بأحدث تقنيات الويب (React 19 + TypeScript + Tailwind CSS v4 + Express Backend) مع دعم الذكاء الاصطناعي (مستشار الهاردوير الذكي).

---

## ✨ المميزات الرئيسية للمشروع

1. **🛠️ مجمع الحواسيب التفاعلي (PC Builder):**
   - اختيار القطع خطوة بخطوة (المعالج، المذربورد، الرام، كرت الشاشة، الباور سبلاي، التخزين، الكيس، التبريد).
   - فحص فوري وذكي لتوافق القطع ومقابس المعالجات (Sockets) ونوع الرام (DDR4 / DDR5).
   - حساب فوري لاستهلاك الطاقة (Wattage) وتقديم توصيات الباور سبلاي المناسب.
   - تجميعات مقترحة جاهزة (اقتصادية 1080p، احترافية 2K، تايتان 4K).

2. **🤖 مستشار القمر الذكي (AI Hardware Advisor):**
   - مساعد تفاعلي يجيب فوراً على استفسارات الميزانيات، مقارنات القطع (مثل Ryzen vs Intel)، ومعدلات الإطارات للألعاب.
   - تكامل مع Google Gemini API مع نظام Fallback ذكي لتقديم إجابات تقنية دقيقة حتى بدون إنترنت أو مفتاح API.

3. **⚙️ لوحة إدارة متكاملة ومحمية (Admin Dashboard):**
   - إدارة كاملة للمنتجات (إضافة، تعديل، حذف، رفع صور متعددة مع ميزة التكبير Zoom).
   - إدارة أقسام المتجر بحرية (إضافة أقسام جديدة، تعديلها، حذفها).
   - التحكم بسلايدر العروض الترويجية والبانرات في الصفحة الرئيسية.
   - إدارة فيديوهات المتجر التعريفية وإمكانية تشغيلها مباشرة.
   - تخصيص ألوان وهوية الموقع (ألوان الأزرار والتدرجات والسمات).

4. **📱 تصميم فائق التجاوب وسريع:**
   - متوافق 100% مع الهواتف الذكية (iOS & Android)، الأجهزة اللوحية، والحواسيب.
   - دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).
   - إمكانية الطلب والتواصل المباشر عبر واتساب.

## 🚀 متطلبات التشغيل (Prerequisites)

- تثبيت **[Node.js](https://nodejs.org/)** (الإصدار 18 أو أحدث).
- تثبيت **Git** على جهازك.

---

## 🛠️ خطوات التشغيل محلياً (Run Locally)

1. **استنساخ المستودع (Clone Repository):**
   ```bash
   git clone https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
   cd <REPO_NAME>
   ```

2. **تثبيت الحزم والمكتبات (Install Dependencies):**
   ```bash
   npm install
   ```

3. **إعداد المتغيرات البيئية (اختياري للذكاء الاصطناعي):**
   - أنشئ ملف باسم `.env` في المجلد الرئيسي وضع بداخله:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```
   *(المشروع سيعمل بشكل كامل حتى بدون إدخال المفتاح بفضل نظام الردود التقنية الذكية التلقائية)*.

4. **تشغيل خادم التطوير (Run Development Server):**
   ```bash
   npm run dev
   ```
   - سيفتح التطبيق على الرابط: `http://localhost:3000`

5. **بناء المشروع للإنتاج (Build for Production):**
   ```bash
   npm run build
   npm start
   ```

## 📁 هيكلية المجلدات الرئيسية

```text
├── src/
│   ├── components/       # مكونات الواجهة (Header, Footer, PCBuilder, AIAdvisor, AdminDashboard...)
│   ├── data/             # البيانات المبدئية والمنتجات والتجميعات
│   ├── App.tsx           # المكون الرئيسي للمتجر
│   └── main.tsx          # نقطة دخول التطبيق
├── server/
│   ├── data/             # تخزين بيانات المتجر المستمرة (JSON Database)
│   └── services.ts       # خدمات السيرفر والذكاء الاصطناعي
├── server.ts             # خادم Express المتكامل مع Vite
├── package.json          # حزم واعتماديات المشروع
└── vite.config.ts        # إعدادات Vite
```
